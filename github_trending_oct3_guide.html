REA

★34.7만 ▶ 8:18

코딩 에이전트를 Ghidra·Hopper·IDA에 연결해 소스 없는 프로그램, Electron·안드로이드 앱, 웹사이트까지 분석. 패킷·SQLite·WASM 분석 추가.

⚠ 호환 깨지는 변경 7건 → 버전 고정 · 공식 저장소와 npm rea-agents만 사용(포크 8.7만) · 타사 SW 분석은 약관·저작권 문제

https://github.com/morluto/rea 를 공식 npm 패키지(rea-agents)로 버전을 고정해 설치하고, 내가 만든 앱 구조를 분석해 줘.

ai-job-search

★6만 ▶ 5:15

Claude Code 구직 도구. 공고 적합도 평가 → 이력서·자소서 초안 → 리뷰어 에이전트 비평 → PDF·채용시스템(ATS) 검사.

⚠ v1.7.3에서 권한 축소(업로드·비밀파일 차단, git push는 매번 확인) · 포크는 항상 공개 → 개인용은 private 저장소

https://github.com/MadsLorentzen/ai-job-search 를 private 저장소로 복제해 설치하고, 이 채용 공고와 내 이력서 적합도를 평가해 줘.

claude-plugins-official

▶ 4:33

Anthropic이 관리하는 Claude Code 공식 플러그인 목록(315개). 기본 연결돼 있어 이름만으로 설치. security-guidance 커밋 리뷰어가 읽기 전용으로.

⚠ 외부(파트너·커뮤니티) 플러그인 내용은 Anthropic이 검증하지 않음 → 설치 전 확인

https://github.com/anthropics/claude-plugins-official 목록에서 security-guidance 플러그인을 설치하고 어떤 시점에 검사하는지 알려 줘.

context-mode

★3.1만 ▶ 3:55

로그·브라우저 기록 같은 긴 도구 출력을 따로 처리해 대화 창(컨텍스트)을 아끼고, 작업 기록은 DB에 두었다가 압축 후 다시 꺼내 줌. "315KB→5.4KB(98%)"는 개발사 발표.

⚠ Elastic License 2.0: 사내 사용 OK, 호스팅 서비스로 재제공 불가

https://github.com/mksglu/context-mode 플러그인을 설치하고, 긴 로그 출력이 컨텍스트를 덜 차지하는지 확인해 줘.

Ghidra

★9.2만 ▶ 3:22

NSA 연구국의 무료 리버스 엔지니어링 도구. 기계어를 읽을 수 있는 코드로 되돌리고, 함수 흐름 그래프·Java/Python 스크립트 자동화, 서버(headless) 모드. REA의 분석 엔진 중 하나.

⚠ 이번 주 서버 인증서 검사 보안 수정 · 다음 12.2는 JDK 25 필요

https://github.com/NationalSecurityAgency/ghidra 최신 릴리스를 설치하고 headless 모드로 바이너리 하나를 분석하는 방법을 알려 줘.

scientific-agent-skills

★5.3만 ▶ 2:46

생물·화학·의학·물리·데이터 분석용 연구 스킬 177개. DB 조회 스킬 하나에 PubChem·ChEMBL·UniProt 등 80개 조회법, 스킬별 워크플로 도해.

⚠ 스킬이 코드 실행·패키지 설치·네트워크 요청까지 시킴 → 한꺼번에 전부 설치 금지(README 경고)

https://github.com/K-Dense-AI/scientific-agent-skills 에서 데이터베이스 조회 스킬 하나만 골라 설치해 줘. 전부 설치하지는 마.

HyperFrames

★6.8만 ▶ 2:11

HTML로 장면을 쓰면 영상으로 렌더(같은 입력 = 같은 영상). 이번 주 릴리스 27번: 음량·무음 측정 hyperframes audio, 720p·480p 렌더, 비영어 받아쓰기 버그 수정.

⚠ 사용 기록 수집 기본 ON · v0.8.164부터 사이트 캡처가 HTTPS_PROXY 미사용(프록시 회사망 확인)

https://github.com/heygen-com/hyperframes 를 설치하고(HYPERFRAMES_NO_TELEMETRY=1), 이 HTML 장면을 720p 영상으로 렌더해 줘.

VoiceStudio

★7.8만 ▶ 1:34

목소리 복제·디자인, 영상 더빙, 받아쓰기, 오디오북을 클라우드 없이 내 PC에서. 휴대폰 QR 원격 앱 미리보기(소스 빌드 필요). 이번 주 별 증가 2위.

⚠ 앱은 AGPL-3.0이나 기본 음성 모델 상업 이용 조건은 별도 · 남의 목소리 복제는 당사자 동의 필수

https://github.com/debpalash/VoiceStudio 를 내 컴퓨터에 설치하고, 내 목소리로 받아쓰기와 더빙하는 순서를 알려 줘.

ruflo

★7.7만 ▶ 0:54

옛 claude-flow. Claude Code·Codex 위에서 전문 에이전트 100여 개를 묶어 동시 실행, 메모리 저장소·터미널 콘솔 포함. v3.57.0은 보안 기본값 정리 중심, 벡터 검색 실제 연결.

⚠ Codex 기본 권한 danger-full-access → workspace-write·on-request로 낮춤 · 경로 우회(CWE-22) 수정

https://github.com/ruvnet/ruflo 최신 버전으로 설치하고, .codex/config.toml에 danger-full-access가 남아 있는지 확인해 줘.

OpenCode

★21.8만 ▶ 6:01

모델 회사에 묶이지 않는 오픈소스 코딩 에이전트. 도구·반복은 내 PC, 모델 API로는 추론만 → 75곳 이상의 모델이나 로컬 모델 선택. 2.0: 서버 하나에 터미널·웹·데스크톱 연결, 코드 모드 기본.

⚠ 기본 설정은 도구 승인 없음 · 10/17 Console 보안 사고 → 저장한 외부 API 키 교체, 격리 환경 권장

https://github.com/anomalyco/opencode 를 설치하고, 도구 실행 전에 매번 승인을 묻도록 권한 설정을 바꿔 줘.

vLLM

★9.4만 ▶ 7:12

공개 언어 모델을 내 서버에서 OpenAI 호환 API로 띄우는 엔진. Ollama와 비슷하지만 연속 배칭으로 처리량이 높아 실서비스용.

⚠ v0.32.0: 기본 CORS 해제 → 브라우저 호출 시 --allowed-origins 지정 · Python 3.11 이상 · 사용 통계 기본 수집

https://github.com/vllm-project/vllm 0.32를 설치하고(Python 3.11+, VLLM_NO_USAGE_STATS=1), 허용 주소를 지정해 OpenAI 호환 서버를 띄워 줘.
